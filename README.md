# Sitio web de Juan Ignacio Jacoubian

Esta carpeta contiene el código de tu web académica, publicada en [juanignaciojacoubian.github.io](https://juanignaciojacoubian.github.io/). El contenido inicial se tomó de tu sitio público de Google Sites y se puede seguir editando.

## Actualizar la web en GitHub Pages

Los cambios en la rama `main` del [repositorio](https://github.com/juanignaciojacoubian/juanignaciojacoubian.github.io) se publican automáticamente. `index.html`, `styles.css`, `portrait.jpg` y `favicon.svg` deben quedar juntos en la raíz del repositorio. La publicación puede tardar unos minutos.

## Conectar el dominio más adelante

Cuando apruebes la versión publicada, configura `www.juanjacoubian.com` como **Custom domain** en **Settings → Pages**. Después cambia los registros DNS del dominio siguiendo la [guía oficial de GitHub](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site). Mantén `juanignaciojacoubian.github.io` para probar cambios hasta ese momento.

El cambio de DNS se hace al final. No necesitas transferir la propiedad de tu dominio a GitHub.

## Editar la web

- Texto, secciones y enlaces: `index.html`.
- Colores, tipografía y tamaños: `styles.css`.
- Fotografía: `portrait.jpg`.

Los enlaces a CV y documentos conservan las direcciones públicas actuales de Google Sites. Antes de publicar, conviene comprobar que apuntan a las versiones más recientes.
