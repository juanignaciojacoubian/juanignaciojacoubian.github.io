# Sitio web de Juan Ignacio Jacoubian

Esta carpeta contiene el código de tu web académica, publicada en [juanignaciojacoubian.github.io](https://juanignaciojacoubian.github.io/) y [www.juanjacoubian.com](https://www.juanjacoubian.com/).

## Actualizar la web en GitHub Pages

Los cambios en la rama `main` del [repositorio](https://github.com/juanignaciojacoubian/juanignaciojacoubian.github.io) se publican automáticamente. `index.html`, `styles.css`, `portrait.jpg` y `favicon.svg` deben quedar juntos en la raíz del repositorio. La publicación puede tardar unos minutos.

## Editar la web

- Texto, secciones y enlaces: `index.html`.
- Colores, tipografía y tamaños: `styles.css`.
- Fotografía: `portrait.jpg`.
- PDF: carpeta `pdf/`. Para actualizar un documento, sustituye el archivo con el mismo nombre y publica el cambio en `main`; los enlaces de `index.html` seguirán funcionando.

La ficha del JMP está en `pdf/Jacoubian_JMP.html`. Si cambian el título, el resumen o la fecha del PDF, actualiza también esa ficha, sus metadatos `citation_*`, el resumen de `index.html` y las fechas pertinentes de `sitemap.xml`.
